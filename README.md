코드는 하나도 고치지 않아도 됩니다.

4. 아래 **Commit changes** 를 누르면 1~2분 뒤 사이트에 반영됩니다

### 방법 2 — 사진을 더 넣거나 빼기

`site.js` 를 열면 아래처럼 사진 목록이 있습니다.

```js
var CAR_PHOTOS = [
    { src: 'images/car-01-white-exterior.jpg', cap: '기아 PV5 · 화이트', alt: '차량 외관' },
    ...
];
```

- **빼기** — 그 줄을 지우거나, 줄 맨 앞에 `//` 를 붙입니다
- **넣기** — `images` 폴더에 사진을 올리고, 아래처럼 한 줄을 추가합니다

```js
    { src: 'images/car-08-새사진.jpg', cap: '사진 아래 설명', alt: '화면을 못 보는 분께 읽어 줄 설명' },
```

> `cap` = 사진 위에 겹쳐 보이는 설명 · `alt` = 사진이 안 뜰 때 대신 나오는 글

목록은 네 종류입니다 — `CAR_PHOTOS`(차량) · `CLEAN_PHOTOS`(소독) · `PICNIC_PHOTOS`(펫크닉 포스터) · `GERM_PHOTOS`(병균)

> 펫크닉 포스터는 글자를 읽어야 해서 **자르지 않고 원본 비율 그대로, 다른 사진보다 크게** 보여 줍니다.

> **실수로 파일만 지워도 괜찮습니다.** 깨진 이미지 아이콘이 뜨지 않고 그 자리만 조용히 사라집니다.

### 사진 준비 요령

- 가로세로 **1600px 이하**, 용량 **장당 250KB 이하**를 권합니다. 느린 모바일에서도 빨리 열립니다
- 화면에 맞춰 잘려 보이므로 **인물이나 동물은 가운데**에 두세요
- 확장자는 `.jpg` 로 맞춰 주세요

`site.js` 의 `BRANCHES` 에 한 줄 추가하면 전화 상담 버튼에 바로 나타납니다.

```js
var BRANCHES = [
    { name: '대표번호',   desc: '어디로 걸어야 할지 모르겠다면', tel: '0507-1417-6722', main: true  },
    { name: '남양주지사', desc: '김승현 대표',                   tel: '010-2300-6722',  main: false },
    { name: '인천지사',   desc: '손진구 대표',                   tel: '010-4707-7334',  main: false }

```

`main: true` 는 테두리를 강조하고 **대표** 표시를 붙입니다.

## 견적 요청서

가격은 사이트에 표시하지 않습니다. 이용자가 이동 정보를 입력하면 **견적 요청서**가 만들어지고,
그걸 복사하거나 내려받아 문자로 보내면 운영자가 금액을 안내하는 방식입니다.

**왜 이렇게 했나** — 출발지·도착지가 매번 달라 자동 요금 계산을 하려면 실제 도로 거리가 필요한데,
길찾기 API 는 브라우저에서 직접 부를 수 없어 서버가 있어야 합니다.

**입력 순서** — ① 언제·어디로 ② 왕복 여부 ③ 탑승 인원과 반려동물 ④ 짐·요청사항

**왕복을 켜면** 돌아오는 길 날짜·시간·픽업 장소를 따로 받습니다.
`가는 길과 반대로 채우기` 를 누르면 출발지와 도착지를 뒤집어 자동으로 채워 줍니다.

**내보내는 방법 두 가지**

| | 무엇을 하나 | 어디에 좋은가 |
| --- | --- | --- |
| **내용 복사하기** | 정리된 글로 클립보드에 복사 | 모바일 — 문자에 붙여넣기만 하면 됨 |
| **견적서 다운로드** | 브라우저 인쇄 기능으로 A4 PDF 저장 | PC — 파일로 보관·전달 |

주소 입력은 **다음 우편번호 서비스**를 씁니다. API 키가 필요 없고 무료이며,
스크립트를 못 불러오는 환경에서는 주소를 직접 입력할 수 있게 자동으로 풀립니다.

입력 내용은 **어디에도 전송·저장되지 않고** 이용자 브라우저 안에서만 처리됩니다.

저장소 `kimyoungbok4531/kimyoungbok4531.github.io` 의 **루트**에 올리면 자동으로 배포됩니다.

- 도메인 등록업체 DNS :
  ```
  A      @     185.199.108.153
  A      @     185.199.109.153
  A      @     185.199.110.153
  A      @     185.199.111.153
  CNAME  www   kimyoungbok4531.github.io
  ```
- GitHub 저장소 → Settings → Pages → **Enforce HTTPS** 켜짐

> 주소를 바꾸실 일이 생기면 세 HTML 의 `canonical` · `og:url` · `og:image` 와
> JSON-LD 의 `url`, 그리고 `CNAME` 파일을 함께 고쳐야 합니다.

## 확인이 필요한 항목

1. **병균·진드기 사진 3장** (`germ-01~03`) 은 네이버 이미지 검색 결과를 잘라 쓴 것으로,

   가능하면 직접 촬영한 사진이나 정식 구매한 스톡 이미지로 바꾸시기를 권합니다.
2. **"99프로는 청소를 대충하는…"** 문구는 요청대로 원문 그대로 넣었습니다.
   경쟁사에 대한 비교·비방 표현으로 해석될 소지가 있어 표시광고법 문제가 생길 수 있습니다.
3. **훈련사 경력**은 이력서에서 경력·자격만 옮겼습니다. 주민번호·자택 주소·개인 연락처는 넣지 않았습니다.

5. **멍비치 포스터**(`picnic-02-beach.jpg`) 는 발표자료 원본 이미지의 하단 목록 글자가 깨져 있었습니다.

   원본 이미지를 고쳐 주시면 같은 이름으로 덮어쓰면 됩니다.

## 접근성과 호환성

- 모바일 우선으로 만들고 768px 이상에서 넓혀 씁니다. 360px 폭까지 가로 스크롤이 없습니다
- 모든 버튼과 링크는 **48px 이상**으로 잡아 손가락으로 누르기 쉽습니다
- 입력칸 글자를 16px 로 두어 아이폰에서 입력할 때 화면이 확대되지 않습니다
- 터치하면 즉시 반응하도록 `:active` 효과를 넣었습니다
- 운영체제의 "동작 줄이기" 설정을 켜면 애니메이션과 부드러운 스크롤이 꺼집니다
- 자바스크립트를 꺼도 본문과 연락처는 읽을 수 있습니다
  (사진 목록·후기·견적 요청서만 자바스크립트가 필요합니다)
- 데스크톱에서 전화 상담을 누르면 **"모바일 환경에서만 이용 가능한 기능입니다"** 안내가 뜨고,
  번호를 눌러 복사할 수 있습니다
